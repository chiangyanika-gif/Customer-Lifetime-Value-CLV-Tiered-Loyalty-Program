# Customer Lifetime Value (CLV) & Tiered Loyalty Program

## 📊 Project Overview
This project focuses on analyzing customer purchasing behavior using Python (Pandas) to calculate Customer Lifetime Value (CLV) and segment customers into a tiered loyalty program (Platinum, Gold, and Silver). The insights derived from this analysis help businesses optimize marketing strategies, allocate CRM resources effectively, and retain high-value VIP customers.

---

## 🛠️ Tech Stack & Tools
- Python: Data cleaning, processing, lifespan calculation, and CLV modeling (`pandas`)
- Microsoft Excel: Data validation, Pivot Table aggregation, and reporting

---

## 📂 Repository Structure
- `online_retail_dataset_CLV.xlsx`: Raw transactional dataset used for the analysis.
- `Online_Retail_CLV.py`: Python script containing the entire data pipeline, CLV formula, and tier assignment logic.
- `Customer_CLV_Tier_Python.xlsx`: Final processed output containing customer-level metrics and assigned tiers.

---

## 📈 Key Insights & Summary (From Pivot Table)
- Total Customers Analyzed: 4,372 customers
- Total Portfolio CLV: 6,588,033.70 
- Customer Tiers Breakdown:
    👑 Platinum Tier (Top 10% High-Value): 438 customers | Generating 4,555,587.23 in total CLV (Highest revenue contributors)
    ⭐ Gold Tier: 874 customers | Generating 1,265,325.34 in total CLV
    🥈 Silver Tier: 3,060 customers | Generating 767,121.13 in total CLV (Large base for future nurturing campaigns)

## 🚀 Business Recommendations
1. VIP Retention (Platinum): Provide exclusive rewards, dedicated customer support, and special privileges to maintain long-term loyalty.
2. Upselling & Cross-selling (Gold): Implement targeted marketing campaigns to encourage mid-tier customers to increase purchase frequency and upgrade to Platinum.
3. Automated Engagement (Silver): Utilize automated email campaigns and promotional vouchers to drive repeat purchases and nurture the large general customer base.
